# 蓝牙遥控小车（考核 · 基础部分第 1 项）

> 目标：小车放在箭头处，用手机蓝牙遥控它通过 1 号区域，不碰 15cm 高的围栏。
> 硬件：STC89C52 + HC-05 + L298N + 2×JGB37-520。

---

## 一、这个工程做了什么

| 功能 | 说明 |
|---|---|
| 单字符遥控 | F 前进 / B 后退 / L 左转 / R 右转 / S 停 |
| 1~9 调速 | 发 `5` 就是 50% 速度，随时可改 |
| 速度斜坡 | 每 20ms 加减 5%，约 0.4s 到全速，避免突然正反转烧 L298N |
| 状态查询 | 发 `?` 回 `M=M D=F S=060` |
| 自动模式入口 | 发 `A` 预留（第二项循迹要用，现在只回 NOT READY） |

代码结构：

```
main.c    指令解析 + 状态机
uart.c    9600 串口，中断 + 环形缓冲
motor.c   L298N 驱动 + 软件 PWM + 斜坡
接线图.png 硬件接线
```

| 器件 | 备注 |

## 三、接线

### 1. 51 → L298N（6 根控制线）

| 51 引脚 | L298N | 作用 |
|---|---|---|
| P1.0 | ENA | 左轮 PWM |
| P1.1 | IN1 | 左轮方向 |
| P1.2 | IN2 | 左轮方向 |
| P1.3 | ENB | 右轮 PWM |
| P1.4 | IN3 | 右轮方向 |
| P1.5 | IN4 | 右轮方向 |

> ⚠️ 普中系列开发板的**蜂鸣器接在 P1.5**。如果你的板子是这样，把 `motor.c` 里的
> `sbit ENB = P1^5;` 改成 `sbit ENB = P2^0;`，接线也跟着改，其它代码不用动。

### 2. 51 → HC-05

| 51 | HC-05 | 说明 |
|---|---|---|
| P3.1（TXD） | RXD | **串 1kΩ 限流**（51 是高电平弱驱动，不要用电阻分压） |
| P3.0（RXD） | TXD | 直连 |
| 5V | VCC | 模块底板自带稳压，接 5V |
| GND | GND | 必须共地 |

### 3. L298N 电源与电机

| L298N | 接到 |
|---|---|
| +12V | 电池正极 |
| GND | 电池负极 **＋ 51 的 GND ＋ HC-05 的 GND** |
| +5V | 可选：给 51 供电（此时不要同时插 USB） |
| OUT1 / OUT2 | 左电机两根线 |
| OUT3 / OUT4 | 右电机两根线 |

### 4. JGB37-520 的 6 根线

- **2 根粗线**：电机电源，接 OUT1/OUT2 或 OUT3/OUT4，不分正负（转向反了就互换）；
- **4 根细线**：编码器 VCC / GND / A / B，**本项目先不接**，包好绝缘。
  以后测速时再接（A/B 接 P3.2/P3.3 或定时器计数），注意编码器 VCC 是 5V，**千万别接 12V**。

> 线色各厂家不统一，以电机说明书或万用表实测为准。

### 5. 必须注意的两点

1. **L298N 的 ENA、ENB 跳线帽必须拔掉**。出厂时它们被短接到 5V，不拔的话 PWM 完全失效，一给信号就是全速。
2. **所有 GND 必须连在一起**：电池负极、L298N、51 板、HC-05。少一根就会出现"能连上但电机乱转/不动"。

## 四、Keil 工程建立

1. 新建工程，器件选 **Atmel → AT89C52**（没有 STC 库就选它，兼容）。
2. 把 `main.c`、`uart.c`、`motor.c` 加入工程，头文件放同一目录。
3. `Options for Target` → Target → **Xtal 填 11.0592**。
4. Output → 勾选 **Create HEX File**。
5. 编译，用 STC-ISP 下载（选对 COM 口，冷启动）。

> 下载时如果提示"正在检测单片机…"，把 HC-05 的 TXD 拔掉再下——P3.0/P3.1 是下载口。

---

## 五、手机端操作

1. 手机蓝牙搜索 **HC-05**，配对密码 **1234**；
2. 装一个"蓝牙串口助手"（任意一款都行）；
3. 连接后，发送框输入单字符（ASCII），**不要勾 HEX 模式**；
4. 发 `F` 小车前进，`S` 停车，`5` 变半速。

| 发送 | 作用 |
|---|---|
| `F` / `B` | 前进 / 后退 |
| `L` / `R` | 原地左转 / 右转 |
| `S` 或空格 | 停止 |
| `1`~`9` | 速度 10%~90% |
| `?` | 查询当前模式、方向、速度 |
| `A` | 自动模式（预留，回 NOT READY） |
| `M` | 回到手动模式 |

---

## 六、调试顺序（重要）

1. **先架空车轮**，电池和 51 都上电；
2. 串口助手发 `?`，应回 `M=M D=S S=060` → 说明串口通了；
3. 发 `F`，看两个轮子是不是**都往前**；
   - 有一个反了 → 交换该电机的两根线（或改 `IN1/IN2` 的顺序）；
   - 两个都反 → 交换两个电机的线，或改代码里的方向；
4. 发 `S` 应停，发 `3` 再发 `F` 应明显变慢；
5. 一切正常再落地，先低速跑，熟悉距离感。

## 七、常见问题

| 现象 | 原因 |
|---|---|
| 电机完全不转 | ENA/ENB 跳线帽没拔、没共地、电池没电、L298N 没上电 |
| 只有一个轮转 | 该路 ENA/IN 线没接好，或该路跳线帽没拔 |
| 发 F 变全速、调不了速 | ENA/ENB 跳线帽没拔（PWM 被 5V 顶死） |
| 能连蓝牙但没反应 | TX/RX 接反、波特率不是 9600、没共地 |
| 收到乱码 | 晶振不是 11.0592MHz，或模块被改过波特率 |
| 一给电机就复位/重启 | 电池电压跌落，换电池或并 1000µF 电容 |
| 转向反 | 交换电机线，或改 `IN1/IN2` |
| 蓝牙连不上 | 模块已连别的设备；或上电时 EN 被拉高进了 AT 模式 |

## 八、可调参数（改这几个就够）

`main.c`：

| 宏 | 默认 | 作用 |
|---|---|---|
| `SPEED_DEF` | 60 | 开机速度 |
| `TURN_PCT` | 60 | 原地转弯速度比例，觉得转太猛就调小 |
| `LINK_TIMEOUT_MS` | 0 | 断线自动停车，设 1500 即 1.5s 没指令就停 |

`motor.c`：

| 宏 | 默认 | 作用 |
|---|---|---|
| `PWM_LEVELS` | 20 | PWM 级数（5% 一档） |
| `RAMP_STEP` | 5 | 每 20ms 变化量，越大起步越猛 |

# 蓝牙控制指令表（HC-05 / BLE 通用）

> 发送方式：手机 App **Text（UTF-8）模式**，发**单个字符**。
> 不要用 Hex 模式，也不要带 `0x` 前缀。
> 固件：`蓝牙遥控小车`，波特率 9600 8N1。
> 更新日期：2026-10-30

---

## 一、手动模式（上电默认）

| 字符 | 作用 | 回包 |
|---|---|---|
| `F` | 前进 | `F` + `OK` |
| `B` | 后退 | `B` + `OK` |
| `L` | 原地左转 | `L` + `OK` |
| `R` | 原地右转 | `R` + `OK` |
| `S` 或空格 | 停车（同时退出自动/调试） | `S` + `OK` |
| `1`~`9` | 速度 10%~90% | `OK` |
| `+` | 右轮补偿 +2%（解决两轮不齐） | `OK` |
| `-` | 右轮补偿 −2% | `OK` |
| `?` | 查询状态 | 见下 |
| `E` | 读上一周期两轮的编码器脉冲数 | `E=左,右 T=160` |

**状态回包格式：**

```
M=M D=F S=060 T=100 X=100 L=08
│   │   │     │     │     └─ 7 路循迹值（bit0=OUT1 … bit6=OUT7，1=压黑线）
│   │   │     │     └─────── 当前允许的最高速度（自动限速）
│   │   │     └───────────── 右轮补偿 T（100 = 不补偿）
│   │   └─────────────────── 当前速度
│   └─────────────────────── 当前方向
└─────────────────────────── 模式：M=手动 A=自动 D=调试
```

> **自动限速 `X`**：右轮补偿后不能超过 100%，所以有效最高速度上限 = `10000 ÷ T`。
> 例如 `T=156` 时 `X=064`，这时按 `9` 也只按 64% 跑——好处是车始终能走直。
> `X` 是**上限**，不是当前速度；当前速度看 `S`。

> 车型默认速度 60%，转弯用 60% × 60% ≈ 36%。

## 二、自动循迹

| 字符 | 作用 | 回包 |
|---|---|---|
| `A` | 进入自动循迹，0.4 秒后按默认 30% 起步 | `AUTO` |
| `A2` | **直接以 20% 起步**（A + 数字，1~9 对应 10%~90%） | `AUTO` |
| `M` | 回到手动 | `MANUAL` |
| `S` | 停车并退出自动 | `OK` |
| `1`~`9` | 自动模式下**实时**调整循迹速度 | `OK` |
| `?` | 查询状态（`M=A`） | 状态行 |

**循迹逻辑：** 7 路加权求偏差 → PD → 左右轮差速。同时压线 ≥5 个、或**丢线**时判定为直角弯，蜂鸣器 + LED 提示 0.5 秒；丢线 100ms 后**原地旋转找线**（朝最后偏的方向），重新压线后恢复循迹；1.6 秒还找不到才停车保护。

## 三、单轮调试模式（发 `D` 进入）

进入后回 `DEBUG ON`。此时**关闭右轮补偿，也关闭死区补偿**，输出的是原始 PWM 占空比——用来测两轮的真实差异和死区。退出回 `DEBUG OFF`。

| 字符 | 作用 |
|---|---|
| `1` | 左轮正转 |
| `2` | 左轮反转 |
| `3` | 左轮停 |
| `4` | 右轮正转 |
| `5` | 右轮反转 |
| `6` | 右轮停 |
| `7` | 两轮同时正转（对比用） |
| `8` | 两轮都停 |
| `+` / `-` | 测试速度 ±5%，**正在转的轮子会立即跟着变** |
| `D` | 退出调试，回手动 |
| `?` | 查询状态（`M=D`） |

> 进入调试时 `1`~`8` 是轮子命令，不再是速度设置；速度用 `+` / `-` 调。

### 死区标定（重要）

电机低于某个占空比根本不转，这个值就是死区，两轮通常不一样。

1. 发 `D` 进调试；
2. 按 `1` 让左轮以 10% 转，然后按 `+` 逐步加大，**记录它刚开始转时的速度**（发 `?` 看 `S=`）；
3. 按 `3` 停左轮，按 `4` 让右轮来一遍，同样记下速度；
4. 把两个数填进 `motor.c` 的 `DEAD_L` / `DEAD_R`，重新编译。

填好后，任何非零速度都会自动从死区往上给，低速不会再出现"一轮转一轮不转"。

## 四、常用操作流程

### 1. 调直（两轮转速不一致）
1. 发 `F`，看车往哪边偏；
2. 往右偏（右轮慢）发 `+`，往左偏发 `-`；
3. 发 `?` 看 `T=` 值，调到走直；
4. 把 `main.c` 的 `#define TRIM_R` 改成该值，重新下载固化。

### 2. 单轮测试
1. 发 `D` → `DEBUG ON`；
2. 发 `7` 两轮同转，观察谁慢；
3. 发 `-` 降到 20% 再看低速差异；
4. 发 `8` 停，发 `D` 退出。

### 3. 循迹
1. 把车放在线上，OUT4 压黑线；
2. 发 `?`，确认 `L=` 的 bit3 为 1（如 `08`）；若为 `7F` 说明极性反了，改 `LINE_ACTIVE_LOW`；
3. 发 `A` 开始循迹；
4. 发 `S` 或 `M` 停止。

## 五、参数速查（main.c 顶部）

| 宏 | 默认 | 作用 |
|---|---|---|
| `SPEED_DEF` | 60 | 手动默认速度 |
| `TURN_PCT` | 60 | 原地转弯速度比例 |
| `TRIM_R` | 160 | 右轮补偿**初值**；上电后编码器闭环会在此基础上自动微调 |
| `LINE_ACTIVE_LOW` | 0 | 压黑线**输出高**（本车实测）；反了改 1 |
| `TRACK_SPEED` | 30 | 进入自动模式的基础速度 |
| `TRACK_KP` | 10 | 循迹比例系数（越大修正越猛） |
| `TRACK_KD` | 4 | 循迹微分系数（抑制摆动） |
| `TRACK_KI` | 0 | 循迹积分系数（0=关闭，纯 PD；偏了再开 1） |
| `CORNER_ON` | 5 | 同时压线 ≥N 个判直角弯 |
| `BEEP_MS` | 500 | 声光提示时长 |
| `DEAD_L` | 15 | 左轮死区 %（`motor.c`，已实测） |
| `DEAD_R` | 10 | 右轮死区 %（`motor.c`，已实测） |

**声光引脚：** 蜂鸣器 `P1.6`、LED `P1.7`，均为低电平有效。
